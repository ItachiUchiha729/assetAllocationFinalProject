# Data

The assignment data is not committed to this public repository because it is
course-provided binary data.

Place the raw factor-model files here:

```text
data/raw/factor_model/
  pandas-frames.2003.pickle.bz2
  covariance.2003.pickle.bz2
  ...
  pandas-frames.2010.pickle.bz2
  covariance.2010.pickle.bz2
```

Alternatively, set `FACTOR_MODEL_DIR` to the folder containing those files:

```bash
export FACTOR_MODEL_DIR=/path/to/FACTOR_MODEL
```
